## 镇民 / Townsfolk

### 厨师 / Chef

- **中文（官方）**：在你的首个夜晚，你会得知场上邻座的邪恶玩家有多少对。
- **English (official)**: You start knowing how many pairs of evil players there are.

### 调查员 / Investigator

- **中文（官方）**：在你的首个夜晚，你会得知两名玩家和一个爪牙角色：这两名玩家之一是该角色。
- **English (official)**: You start knowing that 1 of 2 players is a particular Minion.

### 洗衣妇 / Washerwoman

- **中文（官方）**：在你的首个夜晚，你会得知两名玩家和一个镇民角色：这两名玩家之一是该角色。
- **English (official)**: You start knowing that 1 of 2 players is a particular Townsfolk.

### 图书管理员 / Librarian

- **中文（官方）**：在你的首个夜晚，你会得知两名玩家和一个外来者角色：这两名玩家之一是该角色（或者你会得知没有外来者在场。）
- **English (official)**: You start knowing that 1 of 2 players is a particular Outsider. (Or that zero are in play.)

### 共情者 / Empath

- **中文（官方）**：每个夜晚，你会得知与你邻近的两名存活的玩家中邪恶玩家的数量。
- **English (official)**: Each night, you learn how many of your 2 alive neighbors are evil.

### 占卜师 / Fortune Teller

- **中文（官方）**：每个夜晚，你要选择两名玩家：你会得知他们之中是否有恶魔。会有一名善良玩家始终被你的能力当作恶魔。
- **English (official)**: Each night, choose 2 players: you learn if either is a Demon. There is a good player that registers as a Demon to you.

### 送葬者 / Undertaker

- **中文（官方）**：每个夜晚*，你会得知今天白天死于处决的玩家的角色。
- **English (official)**: Each night*, you learn which character died by execution today.

### 僧侣 / Monk

- **中文（官方）**：每个夜晚*，你要选择除你以外的一名玩家：当晚恶魔的负面能力对他无效。
- **English (official)**: Each night*, choose a player (not yourself): they are safe from the Demon tonight.

### 猎手 / Slayer

- **中文（官方）**：每局游戏限一次，你可以在白天时公开选择一名玩家：如果他是恶魔，他死亡。
- **English (official)**: Once per game, during the day, publicly choose a player: if they are the Demon, they die.

### 士兵 / Soldier

- **中文（官方）**：恶魔的负面能力对你无效。
- **English (official)**: You are safe from the Demon.

### 守鸦人 / Ravenkeeper

- **中文（官方）**：如果你在夜晚死亡，你会被唤醒，然后你要选择一名玩家：你会得知他的角色。
- **English (official)**: If you die at night, you are woken to choose a player: you learn their character.

### 镇长 / Mayor

- **中文（官方）**：如果只有三名玩家存活且白天没有人被处决，你的阵营获胜。如果你在夜晚即将死亡，可能会有一名其他玩家代替你死亡。
- **English (official)**: If only 3 players live & no execution occurs, your team wins. If you die at night, another player might die instead.

### 贞洁者 / Virgin

- **中文（官方）**：当你首次被提名时，如果提名你的玩家是镇民，他立刻被处决。
- **English (official)**: The 1st time you are nominated, if the nominator is a Townsfolk, they are executed immediately.

## 外来者 / Outsiders

### 管家 / Butler

- **中文（官方）**：每个夜晚，你要选择除你以外的一名玩家：明天白天，只有他投票时你才能投票。
- **English (official)**: Each night, choose a player (not yourself): tomorrow, you may only vote if they are voting too.

### 酒鬼 / Drunk

- **中文（官方）**：你不知道你是酒鬼。你以为你是一个镇民角色，但其实你不是。
- **English (official)**: You do not know you are the Drunk. You think you are a Townsfolk character, but you are not.

### 陌客 / Recluse

- **中文（官方）**：你可能会被当作邪恶阵营、爪牙角色或恶魔角色，即使你已死亡。
- **English (official)**: You might register as evil & as a Minion or Demon, even if dead.

### 圣徒 / Saint

- **中文（官方）**：如果你死于处决，你的阵营落败。
- **English (official)**: If you die by execution, your team loses.

## 爪牙 / Minions

### 投毒者 / Poisoner

- **中文（官方）**：每个夜晚，你要选择一名玩家：他在当晚和明天白天中毒。
- **English (official)**: Each night, choose a player: they are poisoned tonight and tomorrow day.

### 间谍 / Spy

- **中文（官方）**：每个夜晚，你能查看魔典。你可能会被当作善良阵营、镇民角色或外来者角色，即使你已死亡。
- **English (official)**: Each night, you see the Grimoire. You might register as good & as a Townsfolk or Outsider, even if dead.

### 红唇女郎 / Scarlet Woman

- **中文（官方）**：如果大于等于五名玩家存活时（旅行者不计算在内）恶魔死亡，你变成那个恶魔。
- **English (official)**: If there are 5 or more players alive & the Demon dies, you become the Demon. (Travellers don't count.)

### 男爵 / Baron

- **中文（官方）**：会有额外的外来者在场。[+2 外来者]
- **English (official)**: There are extra Outsiders in play. [+2 Outsiders]

## 恶魔 / Demons

### 小恶魔 / Imp

- **中文（官方）**：每个夜晚*，你要选择一名玩家：他死亡。如果你以这种方式自杀，一名爪牙会变成小恶魔。
- **English (official)**: Each night*, choose a player: they die. If you kill yourself this way, a Minion becomes the Imp.

## 旅行者 / Travellers

### 窃贼 / Thief

- **中文（官方）**：每个夜晚，你要选择除你以外的一名玩家：明天白天他的投票会被算作负数。
- **English (official)**: Each night, choose a player (not yourself): their vote counts negatively tomorrow.

### 官员 / Bureaucrat

- **中文（官方）**：每个夜晚，你要选择除你以外的一名玩家：明天白天，他的投票算作三票。
- **English (official)**: Each night, choose a player (not yourself): their vote counts as 3 votes tomorrow.

### 枪手 / Gunslinger

- **中文（官方）**：每个白天，当首次投票被统计后，你可以选择一名刚投过票的玩家：他死亡。
- **English (official)**: Each day, after the 1st vote has been tallied, you may choose a player that voted: they die.

### 乞丐 / Beggar

- **中文（官方）**：你只能使用投票标记才能投票。死亡的玩家可以将他的投票标记给你，如果他这么做，你会得知他的阵营。你不会中毒和醉酒。
- **English (official)**: You must use a vote token to vote. If a dead player gives you theirs, you learn their alignment. You are sober & healthy.

### 替罪羊 / Scapegoat

- **中文（官方）**：如果你的阵营的一名玩家被处决，你可能会代替他被处决。
- **English (official)**: If a player of your alignment is executed, you might be executed instead.
